# 🌍 Coriolis — The Rotating World Simulator

An interactive computational physics simulator built with Python and Streamlit.

## Features

- Circular motion
- Centripetal acceleration
- Vertical circular motion
- Coriolis acceleration
- Rotating reference frames
- Earth rotation
- Latitude-dependent Coriolis parameter
- Interactive graphs

## Physics

### Circular motion

v = ωr

### Centripetal acceleration

a = ω²r

### Centripetal force

F = ma

### Coriolis acceleration

aC = -2Ω × v

### Coriolis parameter

f = 2Ω sin(φ)

- Python
- Streamlit
- NumPy
